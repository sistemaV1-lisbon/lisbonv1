# LISBON v1 🎯
### Sistema de Rastreio de Pedrinha com IA

✅ **Desenvolvido para jogo de 3 copos** — detecta a pedrinha alvo e ignora distrações.

## 🧠 Funcionalidades
- ✅ **Identificação exclusiva**: Pedrinha vermelha facetada (conforme cadastro)
- ✅ **Modo Análise**: IA aprende velocidade, trajetória e movimento
- ✅ **Rastreio 100%**: Localiza exatamente qual copo está
- ✅ **Estatísticas completas**: Frequência e % de cada copo
- ✅ **Interface moderna**: Tema escuro, botões intuitivos, celular/PC
